# Synthèse de la SAE
  L'objectif de cette SAE est de développer une application qui possède deux classes et permet de conceptualiser un graphe orienté. D'autres méthodes présentes au sein des classes permettront d'afficher les sommets ainsi que de le représenter sous forme de matrice d'adjacence, ou d'une liste.
